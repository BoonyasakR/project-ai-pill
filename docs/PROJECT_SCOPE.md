# ขอบเขตของงาน: AI Pill Anomaly Detection

## วัตถุประสงค์

สร้างระบบต้นแบบที่ตรวจจับและระบุตำแหน่งตำหนิของยาเม็ด โดยเทรนจากภาพยาปกติเท่านั้น

งานนี้เป็นงานวิจัยต้นแบบ ไม่ใช่ระบบรับรองคุณภาพยาจริง

## สิ่งที่อยู่ในขอบเขต

- ตรวจยาเม็ดชนิดเดียวจากชุดข้อมูล MVTec AD หมวด Pill
- บอกว่ายาปกติหรือผิดปกติ และแสดงตำแหน่งที่ผิดปกติด้วย heatmap
- ใช้ PatchCore เป็นโมเดลหลัก และ PaDiM เป็น baseline
- วัดผลด้วย Image AUROC, Pixel AUROC, AU-PRO, Precision, Recall, F1 และเวลาต่อภาพ
- วิเคราะห์ผลแยกตามตำหนิ 7 ประเภท พร้อม false positive และ false negative
- ทำเว็บต้นแบบด้วย React และ FastAPI 4 หน้า ได้แก่ อัปโหลดภาพ ผลการตรวจ เปรียบเทียบโมเดล และผลการทดลอง
- จัดทำรายงานและสไลด์นำเสนอ

## ส่วนต่อยอด

เว็บตรวจภาพที่มียาหลายเม็ดได้ เมื่อยาวางไม่ทับกันบนพื้นสีเข้ม ระบบแยกแต่ละเม็ดแล้วตรวจด้วยโมเดล PatchCore เดิม ยาเม็ดเดียวที่หมุน กลับหัว เปลี่ยนขนาด หรือไม่อยู่กลางภาพก็ใช้วิธีนี้เช่นกัน

ส่วนนี้ทดสอบบนภาพจำลองที่ตัดแปะจาก MVTec เท่านั้น จึงยังไม่ใช่ผลกับภาพถ่ายจริง

## สิ่งที่อยู่นอกขอบเขต

- จำแนกชนิดตำหนิอัตโนมัติ
- ตรวจยาชนิดอื่น แคปซูล หรือยาในแผง
- ตรวจกองยาที่ซ้อนทับกัน หรือยาบนพื้นหลังสว่าง
- ตรวจแบบ real-time บนสายการผลิต
- ใช้งานจริงหรือรับรองคุณภาพยา
- ใช้เชิงพาณิชย์ เพราะ MVTec AD ใช้สัญญาอนุญาต CC BY-NC-SA 4.0

## ข้อมูล

| ส่วน | จำนวนภาพ | การใช้งาน |
|---|---|---|
| Train | ยาปกติ 227 ภาพ | สร้างโมเดล |
| Validation | ยาปกติ 40 ภาพ | ตั้ง threshold |
| Test | ปกติ 26 ภาพ และมีตำหนิ 141 ภาพ | ประเมินผล |

แบ่ง train และ validation จาก `train/good` ด้วย seed 42 ตามไฟล์ `splits/pill_seed42.json`

## กติกาการประเมินผล

- เทรนจากภาพยาปกติเท่านั้น
- ตั้ง threshold ที่เปอร์เซ็นไทล์ 99 ของคะแนนภาพปกติใน validation
- ล็อกโมเดลและ threshold ก่อนประเมินบน test
- ห้ามใช้ test เลือกหรือปรับโมเดล แล้วรายงานเป็นผลอิสระ
- การทดลองที่เลือกหลังเห็นผล test ต้องระบุว่าเป็น exploratory

## ผลหลัก

ผลหลักของงานคือผล Phase 3 บน test set

| โมเดล | Image AUROC | Pixel AUROC | AU-PRO | Precision | Recall | F1 |
|---|---|---|---|---|---|---|
| PatchCore | 0.950 | 0.981 | 0.942 | 0.984 | 0.865 | 0.921 |
| PaDiM | 0.917 | 0.952 | 0.933 | 1.000 | 0.333 | 0.500 |

## ข้อจำกัด

- ใช้ยาเพียงชนิดเดียว และภาพถ่ายในสภาพควบคุม
- ภาพยาปกติใน test มีเพียง 26 ภาพ และ `pill_type` มี 9 ภาพ ค่ารายกลุ่มจึงแกว่งได้มาก
- validation มีแต่ภาพปกติ จึงวัด recall ของตำหนิไม่ได้
- รันด้วย seed เดียว ยังไม่มีช่วงความเชื่อมั่น
- ยาชนิดอื่นหรือภาพที่ถ่ายต่างสภาพ มักถูกแจ้งว่าผิดปกติ แม้ไม่มีตำหนิ
